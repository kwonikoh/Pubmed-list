여러 모델, 하나의 연구 팀

독립적으로 읽고, 원문과 대조하고, 판단이 다른 부분도 남깁니다.

1

자료와 연구 질문

기존 HIF 통합 CSV도 읽습니다. 모든 입력 행을 보존하고, 선택하지 않은 논문은 미실행으로 남깁니다.

아직 자료를 불러오지 않았습니다.

    2

    모델과 역할

    독립 분석 3개 → 총괄이 출처를 대조 → 근거 문장 검사

    같은 모델을 여러 역할에 사용하거나 역할마다 다른 모델을 지정할 수 있습니다. 모델 ID는 제공자 계정에서 사용 가능한 값을 입력하세요.

    API 연결 설정

    키는 현재 브라우저 입력과 실행 중 메모리에서만 사용합니다. 저장·다운로드 결과에는 넣지 않습니다. ChatGPT·Claude 등의 웹 구독과 API 결제는 별개입니다.

    모델 목록 조회도 해당 제공자에 연결합니다. 키를 입력만 해서는 호출되지 않습니다.

    3

    작게 실행하고 검토

    시연 결과는 실제 연구 분석이 아닙니다. 실제 모드에서도 근거 문장 일치 검사는 과학적 타당성·인과성·문헌의 일관성을 입증하지 않습니다. 오류·불일치도 결과에 보존합니다.
    원문과 검토 흔적을 중심에 두는 연구 보조 도구 · 자동 결론 확정 없음

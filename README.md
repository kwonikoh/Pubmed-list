# Pubmed-list

PubMed 논문을 검색하고 목록으로 정리하는 프로젝트입니다.

## 문헌 스크리닝 결과

- [장기별 HIF-1·HIF-2 기능 요약](results/organs/organ_functions.md)
- [장기별 논문 목록](results/organs/organ_index.md)
- [전체 결과와 다운로드 안내](results/README.md)

첨부 PubMed 자료 10,112편을 보존한 탐색적 스크리닝입니다. 장기 배정은 제목·초록 언급 기반이며, 기능 요약의 대표 근거와 불확실성은 각 항목에 표시했습니다. IF 검증 및 전수 원문 검토는 미완료입니다.

## 연구 에이전트 팀

- [Windows 실행·API 연결 안내](research_agent/README.md)
- [브라우저용 프로그램 ZIP](research_agent/research_agent_starter.zip)
- [화면 미리보기](research_agent/preview.png)

Claude·DeepSeek·OpenAI·Gemini를 역할별로 선택하는 로컬 문헌 분석 도구입니다. 시연·파일 처리·결과 다운로드는 검증했고 실제 모델 API 연결은 키를 설정한 뒤 확인해야 합니다. Python 3.11 이상이 필요하며 추가 패키지 설치는 없습니다.

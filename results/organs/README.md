## 해석 범위

장기 배정은 **제목 근거와 초록 언급을 구분한 스크리닝**입니다. 주대상 장기, 전이 부위, 세포 유래·재료 또는 배경 언급이 섞일 수 있습니다. 같은 논문은 여러 장기와 면역·조혈·발생 범주에 중복됩니다. 세포 유형·암/비암 맥락·기능 키워드·모델 세포주도 함께 제공했습니다.

기능 요약은 **대표 118개 PMID(초록 117편, 제목만 1편)**에 근거한 탐색적 종합입니다. 전체 10,112편의 전수 결론 추출·합의 평가·메타분석이 아닙니다. 반복 관찰, 조건별 반대 방향, 단일 직접 근거, 연관성/가설, 제목만, 근거 부족을 구분했습니다. 근거 부족은 관련 논문이나 효과가 없다는 뜻이 아닙니다.

철회·정정·프리프린트·기간 밖/날짜 경계 기록도 **전체 자료에서 삭제하지 않았습니다.** 기능 해석에 사용하기 전 상태를 확인하도록 표시했습니다. 원래 데이터 기간(2021-10-16~2026-10-16)을 유지했으며 2026-10-18에 새 PubMed 검색을 실행한 결과는 아닙니다. IF는 미확인이며 IF로 제외하지 않았습니다.

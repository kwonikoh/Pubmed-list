**미완료 사항:** IF는 전부 미확인입니다. 확인 대상은 2024 JIF(2025 JCR)이며 IF ≥10 조건 충족 및 전체 검색의 완전성을 검증하지 못했습니다. CNS 계열은 저널명 기반 분류이며 계열·발행연도 확인 후보는 별도 표시했습니다. 요약 파일에만 있는 4,862편의 연구유형은 미확정입니다. 먼저 읽을 23편은 초록을 검토해 기초·중개 13편과 임상 10편을 선정했습니다.

철회·정정 문서, 프리프린트, 기간 밖/날짜 경계 기록도 전체 목록에 보존하고 별도 표시했습니다. 온라인 재검색 및 원문 전수검토 결과가 아닙니다.
